# Willow

A calm online snake game. Move with **WASD**, pick a grid size, and deploy it to Vercel as a standard Next.js app.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repo at [vercel.com/new](https://vercel.com/new).
3. Leave the defaults (Next.js is detected automatically).
4. Deploy. The site will be available on `*.vercel.app`.
